# 博客视觉改版方向：白、灰、靛蓝的简约阅读风格

> 日期：2026-10-13。本文是设计方向与后续实现依据，本轮仅整理方案，未修改博客页面或主题配置。

## 1. 整体方向

将博客调整为以阅读为中心的个人知识站：白色主背景、浅灰分区、深色正文、靛蓝强调色，使用统一的无衬线字体、清晰的标题层级和充分的页面留白。

参考 REA 的干净排版与克制配色，结合 AI Hero Learn 的内容组织方式。首页负责介绍作者和引导阅读，文章页负责舒适阅读，专题页负责组织系列内容。

关键词：**简约、清晰、安静、有秩序、适合长文阅读**。

## 2. 参考网站观察

以下为本次访问时的页面观察与浏览器计算样式；字号会随视口和网站更新变化，不应当作固定规格直接照搬。

| 维度 | [REA](https://rea.tools/) | [AI Hero Learn](https://www.aihero.dev/learn) | 博客采用方向 |
| --- | --- | --- | --- |
| 字体 | 系统无衬线字体，正文基准 16px、行高约 1.65 | DM Sans，正文基准 16px、行高 1.5 | 英文可用 DM Sans，中文使用系统无衬线字体，长文提高行高 |
| 标题 | 首屏标题约 64px，粗体，视觉聚焦 | 主标题约 52px，紧凑行高，层级明确 | 首页适度放大；中文标题保留更充足行高 |
| 背景 | 白底、深灰正文、蓝色链接 | 浅灰页面底色、近白内容区、灰色边界 | 白色为主，浅灰仅用于分区和辅助组件 |
| 留白 | 内容居中，左右宽留白，首屏双栏间距明显 | 左侧导航与正文分离，内容区域宽松 | 首页简洁单主栏，专题页按需设置导航 |
| 组件 | 细边框、简单按钮、局部深色代码区 | 分组导航、轻边框卡片、清晰选中状态 | 统一细边框与小圆角，减少阴影和装饰 |
| 强调色 | 蓝色链接与深色主按钮 | 黄色行动按钮 | 统一改用博客 Favicon 的靛蓝色系 |

参考的是排版原则和阅读体验。REA 的产品安装区、AI Hero 的课程推广条和黄色按钮不需要移植到个人博客。

## 3. Favicon 与配色依据

暂将“这个网站的 Favicon”理解为当前博客自己的图标。已查看仓库中的 `source/favicon.ico`：白色底，深靛蓝与灰色笔刷形图案。如果实际指的是某个参考站的图标，后续再替换色彩来源。

对现有图标做六色量化后，主要深色约为 `#1B1F4C`，主要灰色约为 `#B8BABE`，背景接近白色。它们是图像近似采样值；界面颜色按可读性进一步调整。

### 建议颜色

| 用途 | 建议色值 | 使用规则 |
| --- | --- | --- |
| 页面与内容背景 | `#FFFFFF` | 占据大部分可见面积 |
| 辅助背景 | `#F7F8FA` | 代码块、筛选区、专题导航 |
| 主正文 | `#20232B` | 长文、主要标题 |
| 次级文字 | `#606773` | 摘要、日期、阅读时间；小字避免直接使用图标浅灰 |
| 边框与分隔线 | `#E5E7EB` | 1px，避免每个区块都套卡片 |
| 品牌靛蓝 | `#1B1F4C` | Logo 呼应、主按钮、选中状态 |
| 链接蓝 | `#354A9F` | 正文链接、可操作文本 |
| 浅蓝背景 | `#EEF1FA` | 当前标签、轻提示、焦点区域 |
| 图标灰 | `#B8BABE` | 装饰或非关键信息，不用于小字号正文 |

视觉面积以白色为主、灰色辅助、蓝色少量点缀。避免用大片高饱和蓝色背景、荧光青色和绿色抢占阅读注意力。普通文字对比度目标至少 4.5:1，最终实现时检查所有交互状态。

### 图标处理

- 保留现有图案作为品牌识别，可在导航中以 24–32px 小图标使用。
- 当前 ICO 经 Pillow 读取为 1024×1024，需要检查是否含有合适的小尺寸版本；后续生成 16、32、48px 图标，并检查小尺寸笔刷是否清晰。
- `_config.butterfly.yml` 的 `favicon` 当前为空，根目录已生成首页的 shortcut icon 指向 `/`；实施时应显式配置图标路径，并检查生成结果。

## 4. 字体与文字层级

全站统一无衬线字体。推荐字体栈：

```css
font-family: "DM Sans", -apple-system, BlinkMacSystemFont,
  "Segoe UI", "PingFang SC", "Hiragino Sans GB",
  "Microsoft YaHei", sans-serif;
```

DM Sans 主要负责英文与数字，中文由系统字体呈现。如果更重视加载速度，直接使用 REA 式系统字体栈也可以。采用 DM Sans 时建议本地托管 WOFF2 并设置 `font-display: swap`，避免依赖外部字体服务影响首屏。

| 文字类型 | 桌面端 | 手机端 | 字重 / 行高 |
| --- | --- | --- | --- |
| 首页主标题 | 44–52px | 30–36px | 700 / 1.2–1.3 |
| 文章标题 | 34–40px | 28–32px | 700 / 1.3 |
| 二级标题 | 26–28px | 22–24px | 600 / 1.4 |
| 三级标题 | 20–22px | 19–20px | 600 / 1.45 |
| 长文正文 | 17px | 16–17px | 400 / 1.8 |
| 列表摘要 | 16px | 16px | 400 / 1.65–1.75 |
| 导航、日期、标签 | 13–15px | 13–14px | 400–500 / 1.5 |
| 代码 | 14px | 13–14px | 400 / 1.65 |

正文左对齐，中文不额外拉大字距，不强制两端对齐。通过字号、字重、间距形成层级，尽量减少彩色标题。代码使用 `JetBrains Mono, Consolas, monospace`，避免混入正文装饰字体。

## 5. 页面宽度与留白

以下均为博客建议值，而非参考站实测值。

| 项目 | 建议 |
| --- | --- |
| 全站内容容器 | 最大 1120px，居中 |
| 首页文章列表 | 约 800–880px，避免铺满大屏 |
| 文章正文 | 约 720–760px，中文每行约 40–44 个字 |
| 文章目录 | 大屏右侧 200–220px，正文与目录间隔 40–56px |
| 页面左右边距 | 桌面 40–64px，平板 24–32px，手机 20px |
| 顶部导航高度 | 64–72px，白底、轻分隔线 |
| 导航到主内容 | 桌面 56–80px，手机 32–40px |
| 首页区块间距 | 桌面 64–80px，手机 40–48px |
| 列表条目上下间距 | 24–32px |
| 正文段落间距 | 约 1.2em |
| 二级标题上方 / 下方 | 40–48px / 16–20px |

留白要服务于信息分组：同一条目的标题、摘要和日期靠近，不同条目之间拉开。首页首屏应能看到介绍和部分文章入口，不使用全屏背景图占满首屏。

## 6. 页面组成

### 首页

1. **顶部导航**：图标与博客名称在左，文章、专题、关于、搜索等主要入口在右；其他入口放入“更多”或页脚。
2. **简短介绍**：一句清晰标题与一至两行介绍，可保留一个“关于我”链接。避免大型营销式按钮组。
3. **精选内容**：最多三篇，使用标题、短摘要和轻量标签；仅在封面有信息价值时展示图片。
4. **最新文章**：单列文字列表，标题 → 摘要 → 日期与分类，条目之间用留白或细分隔线。
5. **页脚**：版权、订阅和必要社交链接，使用次级文字。

首页默认收起装饰性侧栏，让文章列表成为主视觉。头像和个人介绍集中在顶部或关于页。

### 文章页

- 标题、日期、分类与阅读时间形成紧凑文章头部，不放大型背景横幅。
- 正文采用稳定阅读宽度，右侧仅保留文章目录；窄屏目录改为可展开入口。
- 引用块使用浅灰或浅蓝底、细蓝色左边线；代码块优先浅灰底和清晰语法色，提供复制按钮。
- 图片限制在正文宽度内，保留必要图注；表格和代码在组件内部横向滚动。
- 文末保留上一篇 / 下一篇、相关文章和评论，减小分享、打赏等模块的视觉权重。

### 专题、分类与归档页

- 借鉴 AI Hero 的分组导航，将系列文章按主题或学习顺序组织。
- 专题页可使用左侧 220px 导航与右侧内容区；无需给首页和普通文章页全部增加左侧菜单。
- 分类使用轻量标签或筛选按钮，归档采用年份与日期列表，统一文字和间距规范。
- 手机端专题导航收起，卡片改为单列。

## 7. 组件与交互

- 圆角统一：按钮约 6px，输入框约 8px，必要卡片约 10–12px。
- 卡片默认白底、1px 灰色边框；主要文章列表可直接铺在页面上，不套外框。
- 主按钮用靛蓝底和白字，次按钮白底与灰色边框。
- 正文链接保留下划线，导航链接用选中状态区分当前位置。
- 悬停仅改变文字、边框或浅色背景，过渡约 150–200ms，避免缩放、漂浮和发光。
- 键盘焦点清晰可见，手机主要点击区域至少约 44px；尊重减少动画的系统偏好。
- 第一阶段以浅色模式为主。若保留深色模式，使用中性深灰背景与浅灰文字，避免回到荧光科技风。

## 8. 当前博客的改造重点

当前采用 Hexo 6.3.0 与 Butterfly，并注入 `source/css/custom.css` 及多个美化脚本。仓库配置中包含图片背景、荧光色主题变量、复杂字体栈，以及模糊、透明度、发光与动画相关功能。以下是基于源码的改造判断，尚未逐页检查当前博客的实际呈现。

| 当前配置 / 实现 | 改造建议 |
| --- | --- |
| 主色 `#00d1ff`、链接 `#18ffff`、绿色悬停色 | 统一为靛蓝品牌色与可读链接蓝 |
| 日夜、桌面及手机背景均引用 `/assets/love.png` | 浅色模式改为白色背景 |
| 全局字体同时混用 YSHST、Quicksand、衬线及无衬线字体 | 统一无衬线字体栈，正文与代码分别配置 |
| 当前全局字号 15.5px | 长文正文增至 17px 左右，配合行高与宽度 |
| 首页横幅与文章封面机制 | 减小首页头部高度，按内容需要保留封面 |
| 注入透明度、模糊、主题色与菜单发光相关节点 | 梳理脚本写入的动态样式，避免覆盖新配色 |
| 侧栏及众多插件依赖 | 按实际启用情况精简展示，保留搜索、目录、分类、评论等阅读功能 |

建议保留现有 Hexo 内容体系，先通过配置和独立样式文件实现，再按需要调整 Pug 模板。改造前需确认 CSS 覆盖顺序、动态主题设置与缓存行为，避免继续堆叠冲突规则。

## 9. 建议实施顺序与验收

1. **基础视觉**：颜色、字体、字号、背景、内容宽度、Favicon 配置。
2. **首页结构**：简化头部、文章列表和导航，整理侧栏。
3. **阅读体验**：文章标题、正文、代码、引用、目录和评论。
4. **统一其他页面**：专题、分类、归档、关于、友链及现有工具页面。
5. **实际检查**：桌面和手机截图、长标题与中英文混排、链接对比度、键盘操作及 Hexo 构建结果。

验收目标：白底与灰色层级稳定，蓝色只强调操作和状态；首页直接呈现阅读入口；长文阅读舒适；手机无整页横向滚动；不同页面使用统一字体、间距和组件规则。
