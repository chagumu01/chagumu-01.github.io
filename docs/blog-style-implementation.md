# 简约博客改版实施记录

日期：2026-10-13。设计依据：[博客风格方案](blog-style-direction.md)。

## 已实施

- 白色主背景、浅灰辅助区、深灰正文与 Favicon 靛蓝色系；正文与次级文字使用可读的颜色。
- 采用系统无衬线字体，省去额外字体加载；长文桌面 17px、手机 16px，行高 1.8。
- 首页改为简短介绍、三个专题入口、单列文章列表；移除首页生活照展示、终端、模拟监控和装饰性侧栏，画廊入口保留在页脚。
- 导航简化为文章、专题、关于、更多与搜索，提供可用键盘操作的按钮和清晰焦点样式。
- 正文最大 760px，桌面右侧显示目录；系列文章在大屏保留知识库导航，较窄屏幕默认收起，可通过“专题目录”展开。
- 归档改为年份、日期与文章标题列表，移除统计图与生肖装饰；分类、标签和资料页统一全站排版。
- 页脚简化，引用、代码、相关文章和评论使用轻量边框与中性色。
- 保留手动深色模式，关闭自动夜间切换；移除旧美化脚本的全站加载，替换为轻量交互脚本，避免旧浏览器配色设置覆盖新主题。
- 配置 `/favicon.ico`，生成 16/32/48px ICO、导航图标及 Apple touch icon。
- 修正关闭加载动画后仍执行加载脚本的问题；Fancybox 4.0.31 与 Meting 使用本地资源，并添加 `skip_render: vendor/**`，防止第三方脚本内的模板占位符被 Hexo 解析。

## 文件与维护

主视觉样式位于 `source/css/minimal.css`，交互位于 `source/js/minimal.js`。保留原有 `custom.css` 作为专用页面组件的基础，新样式在其后加载。

首页、导航、文章与归档相关 Pug 模板已直接调整；后续更新 Butterfly 时应保留这些定制。专题文章范围在 `themes/butterfly/layout/post.pug` 的 `seriesPaths` 中配置，新增系列文章时同步补充。

第三方本地资源位于 `source/vendor/`，保留包的许可证。现有文章内容、链接和专用页面的数据未改写。
